### Hello, I'm Owen!
I'm a Game Developer studying in the Netherlands. When I'm not making games, I love to play them, but also enjoy reading books, watching anime, and creating mods for games I enjoy playing.
I'm a serious worker who's always striving to write the most readable, efficient and maintainable code possible, and also have experience with Blender and Paint.NET to create my own models, textures and animations.
Some projects I have worked on are not displayed on my profile, as they are either private repositories and/or owned by other people. I was not the sole developer for the following projects, all of these are group projects in which I took part. Some notable projects include:
  - Bleep Cares mobile app: 
      A Vuforia-based mobile app which tracks image targets on a wallpaper, allowing the user to play minigames based on the marker scanned. This app is used mainly in hospitals and similar institutions.
  - Fantastische Avonturen (app for the children's book): 
      A Vuforia-based mobile app which tracks image targets in a children's book, allowing parents to connect with their children through an interactive reading experience.
  - Operation Seismic descent (a school group project): 
      A fast-paced movement shooter inspired by Ultrakill and SuperHot. Set in a Cyberpunk styled city, where magical crystals are used as their main source of energy.
